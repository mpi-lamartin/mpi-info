4. Donner la complexité des fonctions précédentes.

<Solution show={frontMatter.cor}>

`fusion u v` s'exécute en $O(|u| + |v|)$ dans le pire cas. Les fonctions `est_vide` et `a_epsilon` parcourent chacune l'expression régulière une fois : leur complexité est $O(|e|)$ en temps et $O(h)$ en espace de pile, où $h$ est la hauteur de l'expression.

</Solution>

## Calcul des ensembles $P(L)$, $S(L)$, $F(L)$

Revoir si besoin dans le cours les définitions des ensembles $P(L)$, $S(L)$, $F(L)$.

5. Écrire sur papier des équations de récurrence pour les ensembles $P(L)$, $S(L)$, $F(L)$.

<Solution show={frontMatter.cor}>

Pour une expression $E$, on note $P(E)$ ses premières positions, $S(E)$ ses dernières positions et $F(E)$ ses facteurs de longueur deux. Les cas de base sont :

- $P(\emptyset)=P(\epsilon)=\emptyset$, $P(a)=\{a\}$ ;
- $S(\emptyset)=S(\epsilon)=\emptyset$, $S(a)=\{a\}$ ;
- $F(\emptyset)=F(\epsilon)=F(a)=\emptyset$.

Pour l'union, on prend l'union des ensembles correspondants. Pour une concaténation $E_1E_2$ non vide :

- $P(E_1E_2)=P(E_1)\cup P(E_2)$ si $\epsilon\in L(E_1)$, et $P(E_1)$ sinon ;
- $S(E_1E_2)=S(E_1)\cup S(E_2)$ si $\epsilon\in L(E_2)$, et $S(E_2)$ sinon ;
- $F(E_1E_2)=F(E_1)\cup F(E_2)\cup(S(E_1)\times P(E_2))$.

Enfin, $P(E^*)=P(E)$, $S(E^*)=S(E)$ et $F(E^*)=F(E)\cup(S(E)\times P(E))$.

</Solution>

## Automate de Glushkov

L'automate de Glushkov n'est pas forcément déterministe. On utilisera le type suivant, où les occurrences de lettres sont numérotées à partir de $1$ et $0$ est l'état initial :

```ocaml
type 'a automate = {
    delta : 'a list array array;
    finaux : bool array;
}
```

Ainsi, si `a` est un automate, `a.delta.(i).(j)` est la liste des lettres portées par les transitions de l'état `i` vers l'état `j`. `a.finaux.(i)` est vrai si l'état `i` est final.
