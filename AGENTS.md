# Instructions pour les agents

## Langue et portée

- Travailler en français sauf demande contraire.
- Préserver les fichiers existants et ne modifier que les éléments nécessaires à la demande.

## Travaux pratiques

- Dans un TP, placer la solution de chaque question immédiatement après cette question.
- Pour un TP composé d'exercices indépendants, comme le TP 1, une correction par exercice est préférable.
- Conserver autant que possible le code des solutions dans un fichier source séparé et importer uniquement la partie utile à chaque question.
- Délimiter les parties importables avec des marqueurs `solution:<id>:start` et `solution:<id>:end`, puis utiliser la propriété `part` du composant `Solution`.
- Une correction non publiée doit rester masquée avec `cor: false`.

## Vérification et livraison

- Utiliser l'environnement Nix déjà fourni par le dépôt pour les vérifications lorsque Nix est disponible.
- Après une modification demandée, vérifier les fichiers concernés, créer un commit et pousser celui-ci sur le dépôt distant, sauf indication contraire de l'utilisateur.
